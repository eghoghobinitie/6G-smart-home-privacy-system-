# 6G-smart-home-privacy-system

The smart home 6G privacy system is a simulated 6G-enabled smart home manager that focuses on privacy aware decision making rather than controlling physical hardware. It
demonstrates the use of environmental context to control the behaviour of connected IoT devices, which then determines the operating mode of the smart home.


# Features
- Home, Away, and Emergency operating modes
- Manual modeswitching
- Panic alert override
- Privacy risk scoring
- Risk based device permission enforcement
- Context-aware mode decision making
- Device capability validation
- 11 simulated IoT devices
- Alert and event logging
- Interactive web dashboard
- Simulated device commands and responses
